# 画像のきまり

- 超バズ特化型は必ずストックから付ける。AI が系統（と中身）を選び、その名義でいちばん使っていない在庫を付ける。合う在庫が無ければ「画像が未準備」で保留。作り直し（切り替え）のときはどれかを必ず付ける。
- バズ特化型・霊視開始型は「付けたり付けなかったり」。直前の投稿に画像が付いていたら次は付けない。付けるのは場所が分からない 1枚だけ。
- 属人型にはストックの画像を付けない。土地移動型・寺社訪問型は「◯◯の画像を入れてください」と案内して保留。人が承認のときに付ける。
- 人が投稿に付けた画像は、その名義のストックに自動で残す。
- 漢字の 2枚は左右に割れた 1文字が指でくっつけると現れる仕掛け。字そのものは本文に書かない。
