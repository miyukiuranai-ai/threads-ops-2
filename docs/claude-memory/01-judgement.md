# 判断メモ（本人の言葉）

- いちばん見るのはインプレッション。判定はフォロワー・平均・中央値と比べない。
- 集客（LINE 追加）が来ている名義には権威性があるので、超バズだけは必ず NG。落ちたら「超バズで様子見＋属人＋バズ特化」を全部入れる。
- 超バズだけにしてよいのは一回も集客が来ていない名義だけ。
- 属人型は伸びにくいのが基本。属人型は貴重。1名義の底は 1日 4〜13件の登録、そこに属人のバズで 20〜30件が乗る。名義を横に増やして底を積む。
- LINE の実データ: 純バズのコメントは登録率 3%、属人（名乗り・霊視開始・暦）のコメントは 20〜40%。
- 4本に増やして同じ書き出しを繰り返した 2〜3日後に表示が 1/10 に落ち、登録も落ちる。
- 参考は「この程度」で使う（兵庫版→大阪版）。名義の色を出しすぎると属人の意味がなくなる。
- 数字は 0〜9 の数字。飾りの記号は禁止。合言葉は絵文字 1つか 2文字以内。
- 同じ文面・同じ画像の使い回しは構わない。
- 「落ちた→バズ→回復」は未検証。レポートでは明記する。
- 母数が少なければ「まだ分からない」と書く。
