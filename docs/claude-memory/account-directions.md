## 画像ストックの使い方（本人 9/12）

- 場所が特定できる画像（鳥居、富士山、寺社）は超バズ特化型だけ。花や開運系のように場所が分からないものだけ文章の型に添える。
- 基本は全名義で使えるものとして貯める（本人 9/12「基本、全員使えるものとして」）。名義専用があればそれを先に。ストックに入れていない画像は使われない。
- 画像は「ある程度ランダムでいい。ただし合図が⛩️なら鳥居、のような一致は大事」「特に指定の無いツイートでは縁起物（系統: 開運）を使ってほしい」（本人 9/14）。系統は画像の種類（水墨画）で書いてよく、説明も同じでよい。ツール側: AI の系統 → 本文・合図の被写体 → 縁起物（開運・縁起）→ 未使用順、の順で選び、無い系統で保留にはしない。

## 直前の投稿の判定 → 次の投稿の型（本人 9/14「一回これ覚えて」）
