**どの投稿が LINE 追加につながったかは切り分けられない**、という前提で運用する（本人の判断、2026-09-03）。

- 代理指標: **コメントが付いていて、いいねも一定ある投稿**を良しとする
- **コメントがよく付く投稿は、返信を重ねることで追加が伸びる**（実体験済み）
- **いいねだけ多い投稿（バズ特化）は追加が悪い**（実体験済み）。高く評価しない
- 名義単位では「表示1万あたりの追加人数」で比べる。**登録率（追加÷表示）と表示数の相関はほぼ算術なので出さない**（「あほでも分かる」と指摘された）。意味があるのは傾き（追加ぶんの取れ高）と名義間の比較
- **LINE 公式の管理画面は1日遅れ**で確定する。ツールに入れるのはいつも「昨日」のぶん。9/3 の uta=18 は途中値なので確定後に上書きが必要

**Why:** 表示・反響の最大化は薄い層を呼ぶ。集客の物差しは LINE 追加しかない。

**How to apply:** 日次レポート（lib/server/report.mjs）の判断軸に反映済み。リサーチ画面の「相関」表示は取り下げて傾き表示に差し替える予定（未着手）。関連: [[strategy-axis]] [[account-directions]]

**レポートに欲しいもの（本人 9/7）**: 前日の各投稿の表示数を一気見できる表。本数を増やして1本あたりの表示が落ちた（うたの4〜5本/日）ような変化を拾って指摘する。「落ちているのでバズ特化を混ぜますか？」のような提案（アナウンス）は出すが、判断は本人。「落ちた→バズ特化→治る」は未検証なので自動では切り替えない。続ける／やめるは引き続き出す。

レポートの提案への返事は画面のボタン（休む／1本／1本バズ／2本／そのまま）で行い、翌日分を作り直す（9/9 実装、directives コレクション）。本人は作り直しの費用を気にする: 1回 ≈ 入力1万・出力2千トークン ≈ Opus で約15円、Sonnet で約6円。「休む」は費用ゼロ。

## LINE 追加の実データで分かったこと（本人提示 9/14。うた 8/26〜9/5、星蘭 8/31〜9/9）
- LINE の追加数は「前日の投稿へのコメント」と動く（1日遅れの確認）。signups に日ごとの数を入れた。
- コメントの質で登録率が桁違いに違う。純バズ（🌱を置いた方は全てうまくいく系）は 641コメント→翌日 21件（3%）。属人（名乗り・霊視開始・暦）の日は 62〜157コメント→23〜33件（20〜40%）。星蘭は 29コメント→24件の日もある。
- いちばん登録が出た形: 1日 2〜3本。朝にバズ特化か暦、夜 23〜24時に名乗り型、間に霊視開始か不安煽り。
- 崩れ方は両名義とも同じ。本数を 4本に増やし、同じ書き出し（「〜方には届きません」）を繰り返した 2〜3日後に表示が 1/10 以下に落ち、追加は 1〜3件になった。表示の崩れが追加の崩れの 1日前に来る。
- 星蘭 9/3 17:07 の名乗り型（17,930表示・161コメント）→ 翌日 38件が最高。うた 8/27 23:59 の貴船由来（23,585表示・191コメント）→ 翌日 41件。

## 表示数の判定（本人 9/14）
- 本人がいちばん見るのはインプレッション。判定はフォロワー数・平均・中央値と比べない（「その考えはやめてほしい」）。全名義共通の絶対値で決める。
- 取るのは投稿の 1時間後と 3時間後（5時間後は 1日4本の名義で次の判断に間に合わないので 3時間に）。3時間後で判定、1時間後に 3,000 超ならその場でバズ。
- 線は 300 / 1,000 / 3,000（私の仮置き。本人が経験で置き換える。settings/impressions と `npm run ops -- lines`）。
- 「悪い」3本連続＝抑制中。内容ではなく本数を減らして間を空ける。
