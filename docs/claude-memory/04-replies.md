# 返信のきまり

- 直近 72時間の自投稿に付いたコメントを取り込む（15分に 1回）。3文字以下は合言葉、それ以上は文章。
- 文章は Claude で normal / negative / spam に分類。negative と spam は送らない。同じ人の同じ名義への別コメントも送らない。
- 被り（同じ人が既定 2名義以上、teamB は 4名義以上に出現）は送らない。
- コメントから 5〜30分遅らせる。連続送信は 20〜60秒。深夜 2〜6時は送らず、朝に「遅延謝罪」で返す。
- 返信の型: 「◯◯様、このたびはご連絡いただきありがとうございます。鑑定文が2000文字を超えてまいりますので、プロフィールのリンクよりご連絡いただけますでしょうか」で LINE へ。
- 停止中でも自動返信 ON の名義は取り込む（投稿は手で、返信は自動）。
