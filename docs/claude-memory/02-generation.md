# 生成のきまり

- 参考投稿は「ほぼそのまま」使ってよい。変えるのは土地の名前、名義の名前、合言葉や絵文字、括弧の種類、一語の言い換え程度。参考に無い要素（名乗り、経歴、比喩、由来話、飾りの情景）を足さない。
- お手本は型ごとに 3本ずつ、日替わりで入れ替えて渡す（上限 8本）。
- 合言葉は「置く人が迷わず打てるもの」。絵文字1つ、または 2文字以内の身近な語。土地移動型・寺社訪問型は県名・市名でよい。直近 12本は避ける。
- 暦は「対象日の暦」に書かれた名前だけ。
- 本文 500 文字以内。空行は本文全体で 2つまで。ハッシュタグ・URL なし。絵文字は行末に 1つまで。
- アスタリスク・✴︎ ✳️ ❇️ の強調、太字は禁止（後処理でも落とす）。
- 合言葉を求める本数は askPerDay の範囲で前日と交互。
- ジッターは本文を書く前にかけ、本文の時刻と予定時刻を一致させる。投稿時にも先頭行の時刻を実際の時刻に書き直す。
