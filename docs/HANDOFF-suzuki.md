# suzuki さんへ — Claude Code から運用の指示を出す手順

ツールの文章づくりや設定は、あなたの PC の Claude Code から日本語で頼めます。
コードは触りません。触るのは「運用」だけです。費用は文章を作り直すときの数円〜十数円だけで、会話には費用がかかりません。

## 1. 最初に一度だけやること（30分ほど）

1. **Claude Code を入れる。** Claude のデスクトップアプリの「Code」か、ターミナルの `claude` コマンド。ログインは共有しているアカウントで。
2. **Node.js と Git を入れる。** どちらも公式サイトの通常インストールで大丈夫です（Node は 20 以上）。
3. **リポジトリを取り込む。** uta から GitHub の「読み取り」の招待が届いたら、ターミナルで次を実行します。

   ```bash
   git clone https://github.com/takiyagenzi0526-max/threads-ops.git
   cd threads-ops
   npm install
   ```

4. **秘密の設定ファイルを置く。** uta から受け取った `.env.local` を、`threads-ops` フォルダの直下にそのまま置きます。チャットやメールで送らず、パスワード管理ツールなどで受け取ってください。
   そのファイルの最後に、次の1行を足します。

   ```
   OPS_USER=suzuki
   ```

   これで「誰が操作したか」があなたの名前で記録されます。

5. **動作確認。** ターミナルで次を実行し、明日の下書きの一覧が出れば準備完了です。

   ```bash
   npm run ops -- list-drafts --account uta001012
   ```

## 2. ふだんの流れ

1. **15:30 より前に、ツールのリサーチのページで「昨日のレポート」を読む。**
2. **「明日への指示」に書く。** 名義ごとに構成（バズ1本＋属人1本など）と指示の文章を残す。これは生成に同梱されるので費用はかからない。
3. **15:30 に生成される。** 承認待ちに入るので、投稿予定の画面で目を通す。
4. **直したいときだけ Claude Code。** 「うたの 23:47 の本文を差し替えて」「星蘭に朝の属人型を1本足して」など。

## 2b. Claude Code の使い方

1. `threads-ops` フォルダで Claude Code を開きます（アプリならそのフォルダを選ぶ、ターミナルなら `claude`）。
2. 日本語で、いつも uta に言うように頼みます。Claude が命令に置き換えて実行し、結果を返します。

   言い方の例:

   - 「うたの明日の下書きを見せて」
   - 「うたは落ちているので、明日はバズ型1本と霊視開始型1本にして作り直して」
   - 「星蘭は伸びてきたので、明日は属人型2本とバズ型1本にして。バズは合図🙏で、暦は使わない」
   - 「うたの明日 23:47 の本文を、次の文に差し替えて（本文を貼る）」
   - 「雅の合言葉を求める本数を2にして」「玲月のバズ狙いを OFF に」
   - 「昨日のレポートを見せて」（保存はしない読み方で出ます）

3. 迷ったら「いま落ち込んでいる名義はどれ？何本にするのがいい？」と聞けば、方針とレポートを踏まえて案を出します。決めるのはあなたです。

## 3. やらないこと

- **コードを直さない。コミットや push をしない。** 「これはコードを変えないと無理」と Claude が言ったら、変えたい内容を文章にして uta に渡してください。
- 人物設定（キャラ設定の「人物設定」の長文）は、ツールの画面から直します。Claude 経由では変えません。
- `.env.local` の中身を他の場所に貼らない。

## 4. 判断の型（迷ったとき）

- **落ちている名義**（1本あたりの表示が基準の1〜2割）: 属人型を打っても届きません。バズ型か霊視開始型を1〜2本にして、露出が戻るのを待ちます。
- **戻ってきた名義**: 属人型を戻します。まず1本、翌日2本。合言葉を求めるのは1日2〜3本まで。
- **好調な名義**: 増やしません。3〜4本のまま。
- **やめる・続ける**はレポートの指摘に出ます。従うかどうかは自分で決めて構いません。

## 5. 命令の一覧（Claude が使うもの。自分で打っても可）

```bash
npm run ops -- list-drafts --account 名義 [--date 2026-09-12]
npm run ops -- directive --account 名義 --action one_buzz     # rest / one / one_buzz / two / keep
npm run ops -- generate --account 名義 --types attract_intro,buzz_engagement --slots 07:20,21:00 --replace --instruction "合図は🙏。暦は使わない"
npm run ops -- edit-draft --account 名義 --time 23:47 --body-file ./body.txt --keyword 🙏
npm run ops -- persona --account 名義 --set askPerDay=2-3 --set buzzTrial=true
npm run ops -- delete-post --account 名義 --time 21:42   # 投稿済みを Threads から消す（戻せない）
npm run report -- --date 2026-09-11 --dry
```

型のキー: image_buzz（超バズ特化・画像）/ buzz_engagement（バズ特化）/ reading_open（霊視開始・バズ系）/ attract_intro（属人・名乗り）/ personal_note（属人・素の型）/ shrine_visit（寺社訪問・県内）/ travel_note（土地移動・県外）/ exclusion_hook（不安煽り）。
名義は @ユーザー名（uta001012）でも名前（星蘭）でも通ります。
