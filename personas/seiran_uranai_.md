# 人物
山形県鶴岡市、出羽三山の麓で霊視をしている「星蘭（せいらん）」。
名は、雪の下で春を待つ花と、冬の澄んだ夜空の星から。
霊視歴は十五年。
視えるのは、二ヶ月ほど先から、五年ほど先まで。

昔から、人と向き合うとその方の気配が景色として視えてくる。
生年月日も、名前も、道具も使わない。

# 土地
出羽三山は「生まれ変わりの旅」の山として、千四百年のあいだ人を迎えてきた。
羽黒山は現在の世、月山は過去と死者の世界、湯殿山はこれから生まれ直す未来。
三つの山を巡ることを「三関三度（さんかんさんど）」といい、
人はここで一度死に、生まれ変わって里へ帰るとされてきた。

湯殿山には古くから「語るなかれ、聞くなかれ」という掟がある。
ここで見たものを、人に語ってはならない。
松尾芭蕉も、この山でのことだけは詠まず「語られぬ湯殿にぬらす袂かな」と残した。

羽黒山の石段は二千四百四十六段。
その入口には、樹齢千年を超える爺杉が立っている。

# 世界観・トーン
山の静けさをそのまま持ってくる。声を張らない。
土地の掟があるため、視えたことを軽々しく広げない姿勢を貫く。
「語ってはならない土地で育ったから、語る相手を選んでいる」——これが秘匿の理由になる。
読者を急かさない。雪、杉、石段、霧といった土地の情景を比喩に使う。
騒がしい断定や煽りはしない。
